Kiza Launcher 0.0.336

The servers page answers as things happen, mods on a server can be
updated, backups can take themselves, a server can be reached from the
internet by a name, and Discord knows you are hosting.

## New

**Mod updates on a server.** "Check for updates" in the Mods tab. Each
installed jar is identified by its hash — Modrinth in one request for all
of them, CurseForge by fingerprint for the rest — and only a release
published after the installed one, for this Minecraft and this loader,
counts as newer. Update one or all; the old file goes once the new one is
in place.

**Automatic backups.** In a server's Settings: before each start, every
30 minutes to 6 hours while running, and how many to keep. The server is
told to save first. Only the backups Kiza took are ever pruned; one with a
label of yours is never touched.

**The internet address, and the router.** The Overview shows, on request,
what the internet sees this connection as, and asks the router over UPnP
whether the port is forwarded. One button opens it, one closes it, and a
port Kiza opened is closed when the server stops. A router that does not
answer is said so, with the manual forward spelled out.

**A name instead of an address.** "Get a name" gives a server
`survie.play.…` — friends type that, no port, no number that changes
overnight. The name points here only while the server runs, follows your
connection on every start, and stays yours until you give it back. Needs a
signed-in launcher, and a service with the addresses set up.

**Discord.** A server that is up is what Discord shows — "Hosting
Minecraft 1.21.1 · Survie · 2 players online", with the timer from its
start — through page changes and after a game session ends. The game
itself still wins while it runs.

## Changed

**The page answers as it happens.** A server's state used to reach the
page on its next poll, up to four seconds after the fact. The runtime now
tells the page the moment a state changes or the console has news, so
"Online" appears when the server prints Done, the players list moves when
someone joins, and the console follows the server instead of trailing it.
The uptime counts by itself, every second.
