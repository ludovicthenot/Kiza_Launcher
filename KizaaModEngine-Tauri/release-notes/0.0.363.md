Kiza Launcher 0.0.363

The Kiza Client has its own settings, inside the game.

## New

**Client settings.** A round gear at the bottom left of the title screen
opens the Kiza Client settings. Each instance keeps its own.

**Your own menu background.** Choose an image, a GIF or an MP4 video as the
title screen's background — with the file dialog or by dropping the file on
the game window — and set how dark the veil over it is.

**Accent colour.** Violet, blue, pink, green or orange for the buttons,
sliders and the emblem's glow.

**More switches.** Turn off the opening animation, the emblem effect, the
button icons, the Kiza style on screens other than the title and pause
menus, the version line at the bottom, or the Kiza line in F3.

## Changed

**Fredoka.** The menus are now set in Fredoka, the rounded face of the
Kiza Client name.
