Kiza Launcher 0.0.343

RLCraft reaches its main menu.

## Fixed

**A blocked mod came back in the wrong version.** When a modpack lists a
mod its author will not let launchers fetch from CurseForge, Kiza offers
the same mod from Modrinth. It took the newest release there, not the one
the pack was built against — RLCraft pins Scape and Run: Parasites 1.9.11
and got 1.10.9, whose new armour material its own mixins turn into a crash
at "Initializing game". The pack's own build is now looked for first, by
file hash and then by name; when Modrinth never had it, the release
closest to the pack is taken and labelled as such in the missing-mods
window.

**Old-style Forge mods were disabled by the fixer.** A `mcmod.info` that
Forge reads and strict JSON rejects, or a jar with no descriptor at all
(ordinary before Minecraft 1.13), was reported as a mod for the wrong
loader, and the compatibility fixer switched it off. Seven of RLCraft's
mods went that way, Switch-Bow among them, and Bountiful will not start
without it. Both kinds are recognised as Forge mods now; only a real
loader mismatch is one.
