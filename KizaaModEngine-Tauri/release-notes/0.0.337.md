Kiza Launcher 0.0.337

A changelog that reads in ten seconds however many releases it covers,
and a clearer word when the address service is not there yet.

## Changed

**One changelog for several releases.** Somebody who skipped four releases
used to get four changelogs stacked end to end. What is new, what was
fixed and what changed are now one list each across every release, each
change with the version it arrived in, newest first. Past a dozen changes
the explanations fold and the bold sentences stand alone; each opens on
its own, and "Read everything" opens all.

**The address service, when it is not there.** Asking for a name from a
service that predates it used to echo the service's own "Only GET is
allowed". It says now that the service does not offer addresses yet.
