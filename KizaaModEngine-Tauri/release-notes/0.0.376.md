Kiza Launcher 0.0.376

## Fixed

**The loading screen shows on Fabric with many mods.** When the game is
too busy loading to draw more than a frame now and then, Kiza's screen
now appears whole on the first of them, with the bar where the game is,
instead of staying empty until the end.

**What's new waits for the launcher's opening.** The list of changes, and
the notice of a channel that has moved, now open once the opening has
finished instead of covering it.
