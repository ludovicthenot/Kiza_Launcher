Kiza Launcher 0.0.382

## New

- **Kizaflux (Experimental).** A Minecraft 26.3 instance can now play on
  Horizon, Minecraft rewritten in Rust, instead of Java: pick Kizaflux as the
  engine when creating a vanilla instance. The first Play downloads Horizon's
  newest signed release and prepares it from your own Minecraft files (about
  three minutes, once). Java mods do not run on it; resource packs, data packs
  and Horizon mods do.
- **The Kizaflux tab.** Each file of a Kizaflux instance with what Kizaflux
  can do with it; Java mods can be brought over with Horizon's own carry-over,
  which keeps their blocks, items, recipes and world generation; Horizon mods
  turn on and off; and a check says whether Kizaflux can join a server.
- **Make a Kizaflux copy** of a Java instance, from its Settings: a new
  instance with copies of its worlds, resource packs, options and servers, and
  whatever of its mods carries over. The Java instance is left as it is.
- **Third-party licences.** Every library Kiza includes is listed with its
  licence, in Settings > About and beside the program.

## Fixed

- The instance sidebar called a NeoForge instance Vanilla.
- The Kiza Client's Vanilla agent now carries the licences of the libraries
  inside it.
