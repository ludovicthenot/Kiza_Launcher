Kiza Launcher 0.0.364

Fixes for the in-game menus.

## Fixed

**Key Binds.** Category headings such as Movement and Miscellaneous are no
longer drawn as buttons.

**Buttons stay lit.** A button you clicked no longer stays violet after the
pointer leaves it. The highlight follows the keyboard only when you move
through a screen with Tab or the arrow keys.

**Client settings are always kept**, including when the game is started
without the launcher.
