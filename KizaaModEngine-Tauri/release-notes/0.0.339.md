Kiza Launcher 0.0.339

The title bar is glass, and the pages slide under it.

## Changed

**The title bar is glass.** Mostly transparent and blurred hard, so what
is behind it shows through softened — the backdrop's glow, and the page
as it scrolls up beneath. The version badge is frosted the same way, and
still the accent.

**Pages scroll under the bar.** Each page starts below it and slides the
rest beneath on the way up. Nothing is hidden at the top.

## Fixed

**The instance footer stays one row.** It wrapped its buttons under the
tiles as soon as the window was not wide enough for everything at full
size. What does not fit now gives way in order — the button labels first,
then the folder tile, then Java — and the row never breaks.
