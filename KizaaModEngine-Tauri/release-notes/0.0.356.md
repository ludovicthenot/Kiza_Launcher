Kiza Launcher 0.0.356

Themes paint the whole window, and Kiza Maker becomes a theme editor.

## New

**The waves follow the theme.** The moving background takes the theme's own
colours instead of always being violet. Nebula looks exactly as before.

**A theme's compact logo** now appears at the head of the title bar.

**Kiza Maker is a theme editor.** It opens straight on the editor, over the
launcher's own pages filled with test instances. Play is only acted out:
nothing is downloaded and no game starts.

## Fixed

**Themes are safer.** Every value a theme carries is checked before it is
used, so a theme can change how the launcher looks and nothing else. The
buttons to create or import an instance, and to create a server, can be
moved and restyled but never hidden.
