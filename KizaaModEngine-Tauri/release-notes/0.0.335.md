Kiza Launcher 0.0.335

The launcher hosts servers now. A second half of the front page, a server
built from an instance in one pass, and a manager with the console, the
players, the mods and the backups of each one.

## New

**Instances | Host.** The front page has two halves. Instances is the library
as it was. Host is the servers this launcher runs, with a Creator and a
Manager under one header — the same title row, the same tools, so flipping
between the two moves nothing else.

**A server from an instance.** From an instance's menu, "Create a server from
this instance". The launcher reads the instance and says what it found —
Minecraft 1.21.1, Fabric, Java 21, 84 mods — and then, mod by mod, whether a
server needs it: 72 compatible, 8 client-only left out, 4 nobody could
classify, listed first and ticked by default because a server missing a mod
it needs does not start while one carrying an extra jar merely ignores it.
Every verdict says where it came from: the jar's own manifest, Modrinth,
CurseForge, or nothing. Untick, tick, pick a world to copy, build.

**Or from scratch, or from a folder.** The creator card — name, version,
loader, Deploy — with the five presets, and beside it every setting a server
is generated with: memory, Java, port, MOTD, seed, difficulty, game mode,
players, online mode, whitelist, PvP, hardcore, icon. A folder that already
holds a server can be imported; what it proves is read — a vanilla jar's
version, Fabric's install file, a Forge or NeoForge library path — and what it
does not is asked for rather than guessed.

**The Manager.** Cards like the library's, the selected one beneath with
Start, Stop, Restart, Kill under a confirmation, Open folder, Clone and
Delete, and seven tabs. Overview: uptime, memory, CPU, world size, the LAN
address to give a friend, and what the crash doctor found when the server
fell over. Console: the last two thousand lines, a line to type into,
history on the arrow keys. Players: who is on with op, kick and ban; the
whitelist, the operators, the banned — each action a command the running
server performs itself. Mods: the folder, the compatibility report on it, and
Modrinth narrowed to this server's Minecraft and loader, with a client-only
mod refused and told why. Files. Backups: make one at any time, put one back
with the server stopped. Settings: Kiza's own line and `server.properties`,
edited in place so a key the page does not know is left exactly as it was.

**The EULA, asked once.** Mojang's terms are shown before the first start,
with a link and a box to tick. The launcher writes `eula=true` only then.

## How it behaves

The state comes from the process, not from the button that was pressed:
Starting until the server prints "Done", Stopping when it is told to stop,
and the exit code decides between Offline and Crashed. A server that was
still running when the launcher last closed is found again through its pid
file and shown as running outside Kiza, with a Kill and nothing else — the
truth, so the user can decide.

Vanilla, Fabric, Forge and NeoForge servers are fetched on the first start
with the Java each one needs, from the launcher's own runtimes. Restoring a
backup backs up the current state first, checks the archive before touching
anything, and puts the previous files back if it fails halfway.

## Not yet

No port forwarding, no public address, no cloud: the servers are for this
machine and its network. No TPS, which vanilla does not report cleanly. Mods
on a server can be added, disabled and removed, not yet updated.
