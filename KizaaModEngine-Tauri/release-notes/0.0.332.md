Kiza Launcher 0.0.332

The in-game menu is made of frosted glass, an installed mod will tell you what
it is and which side of the game it runs on, and a launcher that cannot update
finally says so instead of looking up to date.

## New

**What changed, after it changes.** This window. Kiza updates itself and
restarts, and until now the only sign was a version number that had gone up.
It appears once per update and not again until the next one.

**A page for every installed mod.** Click a mod's name in an instance. Its
author, where it came from, its size, when it was installed and released, every
Minecraft version it covers, and the files it actually put in the instance —
counted from disk rather than from what the archive claimed, so a mod that
unpacked to nothing stops looking like one that worked.

**Client or server, at a glance.** Each mod carries a mark: a screen for one
that only runs where you play, a server tower for one that only runs where the
world is, both when it is needed at each end. Fabric and Quilt mods declare this
themselves; Forge ones often declare nothing, and those say so rather than
guessing.

**Server packs.** With the mods ticked in an export, there is now an option to
keep only what a server needs. A mod nothing could classify is kept and counted:
a pack carrying an extra client jar wastes a little space, and one missing a mod
the world needs does not start.

## Changed

**The in-game menu.** New background, and Minecraft's buttons are drawn in
frosted glass with a rim that catches the light and brightens under the pointer.
Every screen Minecraft wrote, not only the title and pause menus — sliders and
text fields are left alone, because covering a slider hides the handle that says
where the value is. The rows are further apart. Labels are set in a heavier
weight, and the launcher and the menu now use the same typeface, which they did
not before.

**The version badge tells the truth.** It said "Alpha" on every launcher ever
built, because the word was written into it. It names the channel this launcher
actually follows, and says Dev for a build from the development server.

## Fixed

**A warning is no longer reported as a crash.** Any log line containing the word
"Exception" became "The game reported an error", in red — and mods say that word
constantly, usually to say they caught one. Fixing it turned up the opposite
mistake: an OutOfMemoryError names no exception and was never flagged at all. It
is now.

**A refused update says why.** A launcher following a channel it has no key for
checked, was turned away, and reported nothing — it looked up to date while
frozen several versions behind. The reason the service gives is now shown beside
the version, and clicking it opens the settings.

**The settings page stopped redrawing itself.** It subscribed to the whole
updater, which ticks on every chunk of a download, so every row on the page was
rebuilt several times a second while an update came down. The Updates section
also says what the last check found, instead of a spinner that started on its
own and never explained itself.
