Kiza Launcher 0.0.319

Importing a modpack no longer throws the whole thing away because one author
does not allow launchers to download their mod, and the Import button says how
far it has got.

## Fixed

**One blocked mod destroyed the entire import.** Some CurseForge authors switch
off third-party downloads for their project. The import stopped at the first
one, deleted the instance behind it, and reported "Import failed" — so a pack of
twenty-nine mods was lost, along with its configuration and its worlds, because
of a decision nothing in this launcher can change and that you can work around
in a minute if somebody tells you which mod and where.

Every file is attempted now. The instance is built with everything that could
be fetched, and a window lists what could not, each with a button to its project
page. Download the file there and add it with **Add a mod**.

The instance is only discarded when nothing at all arrived — an empty instance
is litter, and importing again is the right answer to that.

## New

**The Import button counts.** A pack of thirty mods is a minute of downloading,
and it used to be a minute of a spinner that could not say whether anything was
happening. It now reads `12/29` while it works.

## Note

If your CurseForge key has stopped being accepted, the launcher will now say so
plainly instead of blaming a mod author — check **Settings → Connections** and
press **Check all**.
