Kiza Launcher 0.0.341

Shader packs and resource packs know who they are.

## New

**Packs with a face.** A shader pack or resource pack was a file name and
a size. Each is now recognised by its hash: title, author, version,
description, icon and the pictures it is chosen by — the same row and the
same information dialog as a mod. Click the name for the gallery, the
facts and a link to the project page. A pack the catalogue does not know
shows what its own files say: the description from pack.mcmeta and the
picture from pack.png.

Files are hashed once and the catalogue is asked once per file; both are
remembered, so the second look costs nothing.
