Kiza Launcher 0.0.318

NeoForge actually works this time, the compatibility warning offers to install
what is missing instead of only naming it, and the in-game menu stops drawing
over half a button.

## Fixed

**NeoForge could not be used at all.** It was in the list, and choosing it
reported that no compatible build existed for your Minecraft version — for
1.21.11, one NeoForge has published forty-five of. The launcher was spelling
the loader `neo_forge` on the wire while the interface, both catalogues, every
mod manifest and NeoForge itself write it as one word, so every request naming
it failed before reaching any code that could have answered. Choosing NeoForge
also asked for a "Version Forge", and a NeoForge modpack was refused as an
unsupported loader.

**There were buttons behind the buttons.** Minecraft draws its own button first
and Kiza covers it, but the cover was rounded and the button underneath is not:
its grey border showed through all four corners of every button in the title and
pause menus.

**Menu labels sat low.** They were centred against Minecraft's line height of
eight pixels while Kiza draws them from its own font at nearer twelve, with a
one-pixel nudge added by hand on top. Both are gone; a label is centred against
the height it is actually drawn at.

## New

**The compatibility warning offers to install what is missing.** "Requires
mixinextras (>=0.3.2) which is not installed" is a sentence you could not act on
without leaving the launcher, finding the right project among the near misses,
and coming back. There is a button beside it now, and the mod arrives with its
own dependencies.

It refuses rather than guesses. A mod's internal id and a catalogue's name agree
often enough to be useful and not often enough to be trusted — MixinExtras is
`mixinextras` in both places, while Fabric API calls itself `fabric` and is
published as `fabric-api`. A handful of known renames are translated, a search
result only counts when its name is the same word, and anything else is reported
as not found. Installing something with a similar name would be worse than
telling you what to look for.

The button does not appear for Minecraft, Java or the mod loader itself. A jar
asking for those is describing the instance it wants, not a file missing from
it.

## Note

The Kiza in-game menu restyles the title screen and the pause menu. Every other
screen — options, video settings, the world list, mod configuration — keeps
Minecraft's own look, which is deliberate. NeoForge instances run normally but
have no Kiza in-game menu yet.
