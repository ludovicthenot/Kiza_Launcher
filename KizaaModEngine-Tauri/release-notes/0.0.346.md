Kiza Launcher 0.0.346

Right-click an instance, and settings that fit on a screen.

## New

**Right-click an instance.** Play, Rename, Change the picture, Open folder,
Check, Export and Delete, from the library without opening it.

**Settings, redrawn.** Nine pages instead of twelve: Language moved into
General, Storage into Downloads, Connections into Advanced. Your account
sits at the top, every page has its coloured icon, and settings are
grouped lists with switches.

**Mod sheets.** A mod's details are one list under its own icon, and the
install window names every dependency, optional ones included, instead of
showing a number.

**Watch an install happen.** Installing a mod shows a bar, which file is
downloading, and a check on each one as it lands.

## Fixed

**The folded sidebar's labels** show in front of the page, not behind it.

**The Mods title** fades into the search bar instead of ending on a line.
