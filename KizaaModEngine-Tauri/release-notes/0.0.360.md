Kiza Launcher 0.0.360

The Kiza menu reaches Forge, and the emblem takes its place at the top.

## Fixed

**Forge 1.21.6 and later.** The Kiza menu now appears on recent Forge
versions, where nothing of it showed before.

**Every button.** The smaller buttons — Edit, Delete, Refresh on the server
list — now look like the others.

## Changed

**The emblem, bigger and higher.** On the title screen the Kiza emblem now
sits where Minecraft's logo used to be, larger, with the buttons below it.
The pause menu and the corner badge show the same emblem instead of the
older logos.
