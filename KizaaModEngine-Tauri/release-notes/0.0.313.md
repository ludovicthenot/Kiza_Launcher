Kiza Launcher 0.0.313

For anyone who came from a build old enough to be called `KizaaMod.exe`: the
version that opens when Windows starts is now the version you installed.

## Fixed

**"Start with Windows" no longer starts the version you replaced.** The startup
entry is written once, when the switch is turned on, and nothing ever looked at
it again. Kiza used to be called `KizaaMod.exe`; anyone who enabled the setting
back then kept an entry pointing at that file, so every reboot started the old
build — with the new one sitting on disk, the shortcuts pointing at it, and
nothing about the install looking wrong. The launcher now checks the entry at
startup and repoints it when it names something else. It never creates one:
somebody who did not ask to start with Windows is not signed up for it by an
update.

**An older launcher left running during an update no longer survives it.**
Removing the previous `KizaaMod.exe` was attempted and its failure ignored, on
the grounds that a locked leftover was dead weight. It is not dead weight — it
is a second, working launcher of an old version, and anything still pointing at
it keeps opening that version: a taskbar pin, a shortcut somebody made
themselves. The install now stops and names the file rather than leaving two
launchers in one folder.

## Note

If the installer asks you to close Kiza, close it. Kiza allows one copy at a
time, and it recognises that copy by name rather than by version — so while an
old launcher is running, opening the new one simply brings the old window
forward. That is the state this release exists to end, and it cannot end itself
while the old one is still up.
