Kiza Launcher 0.0.342

Minecraft 1.12.2 modpacks start again.

## Fixed

**"no lwjgl64 in java.library.path".** The folder of native libraries is
named after the loader build, and the build a launch named was not always
the one the install had filled — a modpack whose Forge was settled after
its libraries were, RLCraft first among them. The game was started with an
empty library path and died before drawing a window. A folder with no
library in it is now filled at launch from the archives the install
already fetched.
