Kiza Launcher 0.0.334

A pack that arrived incomplete can be completed with one click, a Vanilla
instance no longer looks like a modded one with nothing in it, and six mods
that were reported broken were never broken.

## New

**Missing mods, fetched in one go.** When a modpack lists mods its author does
not let launchers download, the launcher used to show the list with a button
beside each one. Five missing mods was five clicks. Now it is one button, a
progress bar with the mod it is on and how many are done, and at the end a
line per mod saying what became of it. Mods that are not published anywhere a
launcher may fetch from stay in the list with their page — a button that would
do nothing is worse than an honest link.

**The Kiza client on Vanilla, without the blur.** Since 1.20.5 every menu
opened over a world blurs the world behind it on every frame, and it is the
most expensive thing a menu does. Kiza paints its own background over the
result, so the blur was work thrown away. It is skipped now on Vanilla
instances; menus look as they did before the blur existed, and the frame rate
in them comes back.

## Fixed

**The client on Vanilla actually starts.** The first build of it was refused
by the game before it drew a frame. The original method is now left exactly as
Mojang shipped it and wrapped, rather than edited.

**Six compatibility problems that were not problems.** A pack showed six and
ran perfectly. Three said a mod required `${file.jarVersion}` — a placeholder
the loader fills in at startup, read here as though it were a number. Three
said Iris, JEI and AddonsLib were made for the wrong Minecraft: they declare a
range that, read strictly, excludes 1.21.1, and NeoForge accepts it anyway
because it keeps its own list of versions that count as each other. The
launcher now keeps the same list, taken from NeoForge itself.

**The performance profiles no longer cap the frame rate.** Two of the three
set a ceiling, the default among them at 240, and the game honoured it as a
hard limit. All three now say unlimited. And the graphics mode is written as
the number Minecraft reads, so "fast" applies for the first time.

## Changed

**A Vanilla instance looks like one.** No Mods section, no Shaders, no Add a
mod, no Sync mods — a plain Minecraft cannot hold any of those, and offering
them invited somebody to add a mod to a game that would then refuse to start.
Resource packs and data packs stay. It opens on Settings, where its memory and
Java live.

**The changelog reads as it was written.** The bold name of each change is set
in its own weight beside a quieter explanation, and the boxes are gone.
